# Segurança

Não abra uma issue pública com senha, keystore, token ou conteúdo de `local.properties`.

Para relatar um problema de segurança, use uma issue privada do GitHub neste repositório ou fale diretamente com o mantenedor. Inclua o que acontece, a versão do aplicativo e, se existir, a revisão do Git. Não inclua a credencial em si.

O que já é verificado em toda alteração está descrito em [ambientes e segredos](docs/ambientes-e-segredos.md).
